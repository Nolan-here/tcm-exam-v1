# 中医执业医师刷题系统 V1

一个无框架、离线优先、以无障碍为核心的网页刷题系统。当前题库合并了用户提供的 2018—2024 年题目与答案解析文件。2018—2022 年扫描 PDF 共收录 2538 道源题，其中 2524 道结构完整；删除 21 道精确重复题，并为避免拆散 B1 题组同步删除 1 道同组题后，新增 2502 道。加上 2023 年 599 道和 2024 年 391 道，网页现有 3492 道题。

项目维护规则见 `AGENTS.md`，当前开发状态和已知问题见 `PROJECT_STATE.md`，重要长期决定见 `DECISIONS.md`。

## 当前界面

首页只有两个操作按钮：

- 复习模式：可选择 10、50、100 或自定义题量，每页最多 10 题。按 `A1/A2`、`A3`、`B1` 分段排列，A3 共用题干和 B1 共用备选答案均按完整题组抽取且不跨页。选择答案后，对错状态直接追加在该选项末尾，不使用弹出式播报，也不公布未选择选项的状态；第一次答错时自动展开“本题讲解”，第一次答对时讲解保持折叠。复习时可以自由返回任何页面。
- 考试模式：四个单元分别独立开始，每次选择一个单元完成 150 题，四个单元合计 600 题，但不是一次连续作答 600 题。每页最多 10 题。组卷时按 2023 年原卷的单元题型结构分别抽取，并保持 `A1/A2`、`A3`、`B1` 题型分段顺序；第一单元不抽取 `A3`。同一页面不混合题型，题组不跨页。完成一种题型后需要确认，确认进入下一题型后不能返回或修改上一题型；刷新后可从当前题型继续。交卷前不判断对错或显示讲解，交卷后显示答对数、答错数、错题及解析。

设置、科目、难度、错题本、收藏、重点题、社区、排行榜和强制联网入口均未显示。升级前已保存在 IndexedDB 中的历史数据不会被自动删除。

## 启动

需要 Node.js 18 或更高版本：

```powershell
cd "D:\Codex\Projects\tcm-exam-v1"
npm start
```

然后在 Chrome 或 Edge 打开：

```text
http://127.0.0.1:4173
```

不要直接双击 `index.html`。使用本地 HTTP 服务才能可靠注册 Service Worker，并获得稳定的 IndexedDB 来源。

## GitHub Pages 长期测试

公开测试地址为 `https://nolan-here.github.io/tcm-exam-v1/`。网址可直接打开复习系统，不需要输入访问密钥。推送到 `main` 分支后，GitHub Actions 会运行测试并发布 `pages-dist` 中的静态网页。

GitHub Pages 和当前 GitHub 仓库均为公开访问，任何获得网址的人都可以打开网页并读取公开题库。答题数据仍只保存在各自浏览器的 IndexedDB 中，不会上传到 GitHub。

## 测试

```powershell
npm test
npm run audit:bank
npm run audit:quality
```

`audit:bank` 默认读取应用正式汇总入口 `js/questions-bank.js` 的 `QUESTIONS` 导出，因此审计范围始终是当前应用实际加载的全部题目；新增年份或题目进入正式汇总入口后会自动纳入。报告动态列出实际题数、年份、题型、题组、结构错误和内容质量警告。结构错误会使命令失败，内容警告会保留问题题目供核对，但不会为了得到绿色结果而被过滤。

`audit:quality` 同样动态读取正式 `QUESTIONS`，用于第一阶段全库质量候选扫描。它逐题检查题干、选项、解析、题组题干和共用选项，报告水印、题号、题型标签、异常空格、括号、疑似 OCR 字符、缺失解析和重复题答案正文冲突。结果只是待核对候选，不能据此自动修改医学内容；可使用 `--output tmp\full-bank-quality-audit\phase1-scan.json` 保存逐条 JSON 报告。

2018—2022 扫描 PDF 的来源专项审计仍可单独执行：

```powershell
npm run audit:history
```

专项审计用于保留该批扫描文件特有的 OCR 和原题号检查，不代表当前完整题库范围。

## 题库导入

- 网页总题库入口：`js/questions-bank.js`
- 原始来源确认修复层：`js/source-confirmed-question-repairs.js`；只在正式汇总入口应用逐字段修复，并以修复前值断言防止底层题库变化后静默误改。
- 2023 年题库：`js/questions-2023.js`
- 2024 年题库：`js/questions-2024.js`
- 2018—2022 年题库：`js/questions-2018-2022.js`
- 2018—2022 年扫描 PDF 导入脚本：`scripts/import_scanned_history.py`
- 扫描 PDF OCR 脚本：`scripts/ocr_scanned_pdfs.py` 与 `scripts/ocr_*_windows.ps1`
- 2023 年可重复导入脚本：`scripts/import_2023_docx.py`
- 2024 年可重复导入脚本：`scripts/import_2024_docx.py`
- 题库版本：`2018-2024-pdf-docx-dedup-grouped-v5`
- 合并后题数：2018 年精选单元 162 道；第一至第四单元分别为 882、812、846、790 道

考试组卷配额以用户提供的 2023 年完整原卷为蓝本：第一单元 `A1/A2 110 + B1 40`；第二单元 `A1/A2 95 + A3 17 + B1 38`；第三单元 `A1/A2 87 + A3 33 + B1 30`；第四单元 `A1/A2 80 + A3 36 + B1 34`。每次进入考试时在对应单元、对应题型的题池中随机抽取。抽题以完整题组为最小单位，并使用不拆组的精确题量算法，因此每单元始终为 150 题。

Word 导入脚本会读取正文、表格和浮动文本框；扫描 PDF 导入会综合 Windows 中文 OCR 的两个分辨率结果与 PaddleOCR PP-OCRv6 高精度复核结果，再按原题号将题目与答案解析对应。两条导入路径都会保留 A3 的共用题干、B1 的共用备选答案和题组边界，并校验题干、A—E 五个选项、答案和解析。脚本不会修改用户提供的原文件。

2018—2022 年源题中有 14 道未加入：2022 年第 75 题原页只有 A—D 四个选项；第 460、490 题原页存在三个以上“待补充”占位选项；第 509、514 题原页只有选项而没有题号题干；另有 3 组共 9 道 A3 题在题目 PDF 中没有可可靠对应的共用题干。OCR 检出的分歧均回到高分辨率扫描页核对；页眉、水印、下一题题号和异常符号等固定噪声已在导入时移除。去重以规范化后的完整题干和五个选项为准，共移除 21 道与已有题库或本批次相同的题；另为避免拆散 B1 题组，同步移除 1 道重复题的同组题。

2018—2022 年答案解析文件中原有 22 道题未提供可用解析，另有 102 道 2021 年题目只写“略”。对本批 2018—2022 年题库复查又发现 27 道题仅写“实记题”或带 OCR 标记的“略”，以及 4 道遗漏或仅剩下一题题号的无效解析。以上共 155 道题均已补充简明复习解析，并在每条末尾明确标注“（由AI查询）”，与原文件解析相区分。当前完整题库仍待处理的内容质量问题见 `PROJECT_STATE.md`。

## 数据与隐私

- 学习数据保存在浏览器 IndexedDB 中，数据库名为 `tcm-exam-v1`。
- 新旧会话以题库版本和试卷格式版本区分；旧记录会保留，但不会被误当成当前分组题库会话加载。连续作答产生的 IndexedDB 保存会按顺序执行，避免较早的写入覆盖题型锁定游标。
- Service Worker 缓存网页外壳与完整题库，可在首次成功加载后离线使用。
- 当前简化界面不提供备份、恢复或联网同步入口，底层旧数据结构仍予保留。

## 键盘与读屏操作

- `Tab`、`Shift+Tab`：在控件之间移动。
- 方向键：在同一题的单选项之间切换。
- 空格键：选择当前选项。
- `Enter`：按下当前按钮或提交页码。

系统不拦截 `A`—`E` 等字母按键。每个单选框的无障碍名称包含选项字母、选项正文及已有作答状态，避免读屏把选项框和正文拆成两个浏览对象。B1 共用备选答案和交卷后的选项使用普通段落，不使用会被读屏额外朗读“项目符号”的列表结构。题目使用原生标题、单选框、分组语义、`details` 和 `dialog`，优先兼容 Windows Chrome/Edge 下的 NVDA、争渡读屏，以及 iPhone Safari 下的 VoiceOver。

## 医学内容声明

题目与解析按用户提供的整理文档导入。结构完整性已自动校验，但这不等同于医学内容、答案或原文排版已由专业教研人员复核；正式备考或公开发布前仍建议逐题审核。
