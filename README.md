# 中医执业医师刷题系统 V1

一个无框架、离线优先、以无障碍为核心的网页刷题系统。当前题库合并了用户提供的 2023 年题干、答案解析文档与 2024 年一试整理文档。2023 年源题 600 道，去除 1 道重复题后新增 599 道；加上原有 2024 年 391 道，网页现有 990 道题。

## 当前界面

首页只有两个操作按钮：

- 复习模式：可选择 10、50、100 或自定义题量，每页最多 10 题。按 `A1/A2`、`A3`、`B1` 分段排列，A3 共用题干和 B1 共用备选答案均按完整题组抽取且不跨页。选择答案后，对错状态直接追加在该选项末尾，不使用弹出式播报，也不公布未选择选项的状态；第一次答错时自动展开“本题讲解”，第一次答对时讲解保持折叠。复习时可以自由返回任何页面。
- 考试模式：四个单元各随机组成 150 题，共 600 题，每页最多 10 题。组卷时按 2023 年原卷的单元题型结构分别抽取，并保持 `A1/A2`、`A3`、`B1` 题型分段顺序；第一单元不抽取 `A3`。同一页面不混合题型，题组不跨页。完成一种题型后需要确认，确认进入下一题型后不能返回或修改上一题型；刷新后可从当前题型继续。交卷前不判断对错或显示讲解，交卷后显示答对数、答错数、错题及解析。

设置、科目、难度、错题本、收藏、重点题、社区、排行榜和强制联网入口均未显示。升级前已保存在 IndexedDB 中的历史数据不会被自动删除。

## 启动

需要 Node.js 18 或更高版本：

```powershell
cd "D:\Codex\Projects\tcm-exam-v1"
npm start
```

然后在 Chrome 或 Edge 打开：

```text
http://127.0.0.1:4173
```

不要直接双击 `index.html`。使用本地 HTTP 服务才能可靠注册 Service Worker，并获得稳定的 IndexedDB 来源。

## GitHub Pages 长期测试

公开测试地址为 `https://nolan-here.github.io/tcm-exam-v1/`。推送到 `main` 分支后，GitHub Actions 会运行测试并发布 `pages-dist` 中的静态网页。

GitHub Pages 只提供静态托管，因此访问密钥页面属于简单遮挡，不能代替服务器端权限控制。密钥本身不以明文写入发布脚本，但公开仓库的源码和题库仍可被任何人查看。访问通过状态仅保存在当前浏览器中，有效期七天；答题数据继续保存在浏览器 IndexedDB，不会上传到 GitHub。

## 题库导入

- 网页总题库入口：`js/questions-bank.js`
- 2023 年题库：`js/questions-2023.js`
- 2024 年题库：`js/questions-2024.js`
- 2023 年可重复导入脚本：`scripts/import_2023_docx.py`
- 2024 年可重复导入脚本：`scripts/import_2024_docx.py`
- 题库版本：`2023-2024-docx-dedup-grouped-v2`
- 合并后四单元题数：286、218、258、228

考试组卷配额以用户提供的 2023 年完整原卷为蓝本：第一单元 `A1/A2 110 + B1 40`；第二单元 `A1/A2 95 + A3 17 + B1 38`；第三单元 `A1/A2 87 + A3 33 + B1 30`；第四单元 `A1/A2 80 + A3 36 + B1 34`。每次进入考试时在对应单元、对应题型的题池中随机抽取。抽题以完整题组为最小单位，并使用不拆组的精确题量算法，因此每单元始终为 150 题。

导入脚本会读取 Word 正文、表格和浮动文本框，按单元及原题号配对题干与答案解析，同时保留 A3 的共用题干、B1 的共用备选答案和题组边界。脚本校验每题的题干、A—E 五个选项、答案和解析，并拒绝生成不完整题库；不会修改 Word 原件。2023 年答案 Word 中有 9 道题只保留了解析、缺少答案字母，已使用用户此前提供的同版答案 PDF 逐页核验补齐；去重采用规范化后的完整题干精确匹配，高相似题只报告、不擅自删除。2024 年第四单元第 59—61 题因题型标题误插造成的断组已按原文病例关系恢复为同一 A3 题组。

## 数据与隐私

- 学习数据保存在浏览器 IndexedDB 中，数据库名为 `tcm-exam-v1`。
- 新旧会话以题库版本和试卷格式版本区分；旧记录会保留，但不会被误当成当前分组题库会话加载。连续作答产生的 IndexedDB 保存会按顺序执行，避免较早的写入覆盖题型锁定游标。
- Service Worker 缓存网页外壳与完整题库，可在首次成功加载后离线使用。
- 当前简化界面不提供备份、恢复或联网同步入口，底层旧数据结构仍予保留。

## 键盘与读屏操作

- `Tab`、`Shift+Tab`：在控件之间移动。
- 方向键：在同一题的单选项之间切换。
- 空格键：选择当前选项。
- `Enter`：按下当前按钮或提交页码。

系统不拦截 `A`—`E` 等字母按键。每个单选框的无障碍名称包含选项字母、选项正文及已有作答状态，避免读屏把选项框和正文拆成两个浏览对象。题目使用原生标题、单选框、`fieldset`、`details` 和 `dialog`，优先兼容 Windows Chrome/Edge 下的 NVDA、争渡读屏，以及 iPhone Safari 下的 VoiceOver。

## 医学内容声明

题目与解析按用户提供的整理文档导入。结构完整性已自动校验，但这不等同于医学内容、答案或原文排版已由专业教研人员复核；正式备考或公开发布前仍建议逐题审核。
